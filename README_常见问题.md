# 常见问题

## 打开后提示未配置 API Key

请检查 `backend\.env` 是否存在并正确填写：

```env
DASHSCOPE_API_KEY=你的API Key
QWEN_BASE_URL=你的API地址
QWEN_TEXT_MODEL=模型名称
```

## 审查很慢

完整审查通常需要 2-5 分钟。论文越长、模型越慢。

## 模型服务异常

多为 API 服务波动或网络问题。请稍后重新审查，或检查 API Key 额度。

## 推荐期刊显示"暂不推荐直接投稿"

说明当前稿件可能更适合作为课程论文、竞赛论文、技术报告，或需补强后再投稿。

## 系统替代同行评审吗？

不能。本系统仅提供辅助性学术审查建议，不替代同行评审、导师判断或编辑部决定。

## 上传论文是否安全？

请在可信的本地环境使用，不要上传涉密、未授权传播或高度敏感的论文。
