# 后端要求验收说明

本说明仅核对后端职责，前端弹窗、页面术语提示、组件渲染和页面跳转由前端工程负责。

## 版本基线

- 文档解析采用当前归档中的最新多格式与文本锚点版本。
- 评价服务以五维评价版本为唯一运行基线。
- 早期评价版本和状态补丁只保存在历史目录，不被当前代码导入。
- 当前评价基线之上只增加后端统筹需要的状态协议、模型超时和低随机性配置。
- 审计服务已扩展为支持五个维度及部分成功输入。

| 后端要求 | 实现情况 |
| --- | --- |
| 评价结果稳定 | 模型评价固定为低随机性；相同文件默认命中内容哈希缓存，重复上传返回同一报告；支持 `force=true` 主动重评 |
| 缩短审查时间 | 五维评价采用受控并发；取消流程级整组重跑；重复文件直接命中缓存；默认关闭视觉识别 |
| 请求超时 | 提供模型超时和完整审查总超时，超时自动返回错误工单 |
| 错误监控 | 上传异常、审查异常、超时和部分评价失败均可归档为 SQLite 工单 |
| 运行指标 | `/api/metrics` 汇总成功、失败、缓存命中次数及平均耗时 |
| 状态协议 | 支持 `success`、`partial_failure`、`failed`；失败维度不会作为 0 分 |
| 审计输入 | 只将成功维度送入结果复核；全部失败不进入复核 |
| 重试控制 | 网络、格式、质量问题在单个评价维度内定向重试，不整组重跑 |
| 学术影响力 | 已作为第五个评价维度接入 |
| 投稿建议 | 学术影响力结果包含结构化期刊层级建议 |
| 原文定位 | 解析阶段生成页码、段落、文本块、字符区间和 PDF 坐标 |
| 风险定位绑定 | 主控根据证据原文自动给风险条目和证据引用补充锚点与坐标 |
| 反馈归集 | `/api/feedback` 保存评分、分类、意见和可选联系方式 |
| 无水印报告 | `/api/reports/{id}/export` 校验反馈权益后生成无水印 Markdown 报告 |
| 深度诊断 | `/api/reports/{id}/deep-diagnosis` 消耗一次权益并生成结构化专项诊断 |
| 优先通道 | 反馈令牌可在下次上传时进入优先队列，并消耗一次优先权益 |
| 版本知情权 | `/api/releases` 使用反馈权益查询版本更新记录 |

## 自动化验证

```powershell
python -m unittest discover -s tests -v
python -m unittest evaluation_agents_delivery.test_service -v
```

当前离线测试覆盖：

- 全部失败、部分失败和审计异常降级；
- 风险条目到页码、段落和文本块的绑定；
- API 健康检查和上传类型校验；
- OpenAPI 前端接口契约和“仅后端”根地址说明；
- 相同论文稳定性缓存；
- 反馈提交、权益令牌、无水印报告、深度诊断和版本记录；
- 五维评价服务结构。

已使用随附测试论文完成真实模型端到端验证：五个评价维度均成功，综合审计通过，问题和参考文献证据均能定位。为避免泄露密钥或携带个人运行数据，正式交付目录不保留 `.env`、运行缓存、日志和完整测试结果；使用者需从 `.env.example` 复制配置并填入自己的有效密钥。
